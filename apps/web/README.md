# Candle Intelligence — Web

Next.js 16 · TypeScript · Tailwind 4 · shadcn/ui (base-nova) · TradingView Lightweight Charts 5 · TanStack Query 5.

Current page: **Chart Viewer** (`/`) — XAUUSD M1/M5/M15/H1 candles from the validated
dataset, scroll-back history, UTC / New York / IST display, and a data-health panel.

## Run

The app proxies `/api/*` to the research API (`ci-api`, port 8000), so start that first.

```powershell
..\..\.venv\Scripts\ci-api.exe     # from apps/web, or `ci-api` with the venv active
npm run dev                          # http://localhost:3000
```

Set `CI_API_ORIGIN` to point the proxy elsewhere.

## Notes

- The API serves validated Parquet datasets only; the web app never talks to MT5.
- Candles built from fewer M1 bars than their length (gaps, session edges, the bar still
  forming at dataset end) are drawn grey and labelled "incomplete".
- Lightweight Charts' TradingView attribution logo is kept on, as its license requires.
- `AGENTS.md` / `CLAUDE.md` are generated by `next dev`; keep them committed.
